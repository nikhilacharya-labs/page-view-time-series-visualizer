# Demographic Data Analyzer

freeCodeCamp Data Analysis with Python project.

## Files

- `demographic_data_analyzer.py` - main solution
- `main.py` - simple local runner
- `requirements.txt` - Python dependency
- `adult.data.csv` - **download the official project dataset and place it here**

## Run

```bash
pip install -r requirements.txt
python main.py
```

## Important

Keep the dataset filename exactly:

`adult.data.csv`

For the freeCodeCamp submission, make the GitHub repository **Public** and submit the repository URL in the Solution Link box.
